#MortDB

[![CI](https://github.com/prakharchoudhary/mortdb/actions/workflows/ci.yml/badge.svg)](https://github.com/prakharchoudhary/mortdb/actions/workflows/ci.yml)

MortDB is a durable key-value store built on an LSM tree, written in Rust, meant to be deployed for real-world use-cases and released as open source.
